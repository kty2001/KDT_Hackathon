# 5-1. NightOwls · AI Hub 미설치 사유 — 저장공간 (2026-07-27)

### 5-1. NightOwls · AI Hub 미설치 사유 — 저장공간 (2026-07-27)

> ⚠️ **2026-07-29 정정 — 이 절의 전제가 틀렸다.** 아래는 **C드라이브만** 보고 내린 판단이다. 실측 결과 **D드라이브에 349.8 GiB 여유**가 있었고, 게다가 `D:\datasets\`에는 이미 팀이 받아둔 기존 데이터셋 zip들이 있었다. **저장공간은 처음부터 제약이 아니었다.**
> NightOwls는 이 정정에 따라 취득에 착수했다 (→ 5-2). AI Hub도 같은 이유로 보류 사유가 해소됐으나, "주간 데이터라 야간화 증강이 선행돼야 한다"는 **별개의 사유**는 그대로 유효하다(아래 대응방침 3번).

두 데이터셋 모두 **취득 절차상의 장벽은 없다.** NightOwls는 사이트 등록 후 연구용 승인이 즉시 나고, AI Hub 인도보행은 한국 휴대폰 본인인증 후 신청하면 자동승인된다.
설치하지 않은 실제 사유는 **학습 PC의 로컬 디스크 여유 공간 부족**이다.

| 항목 | 실측 (2026-07-27) | 재실측 (2026-07-29) |
|------|-------------------|---------------------|
| C드라이브 여유 | **81.7 GiB** (87.7 GB) | 77.1 GiB |
| **D드라이브 여유** | *(확인 누락)* | **349.8 GiB** ← 실제 가용 공간 |
| 이미 사용 중 (C) | 394 GiB | 398.7 GiB |

- **AI Hub 인도보행**: 장애물 BBox/폴리곤 + 노면 마스킹 + **Depth**까지 포함된 대규모 구성이라 전량 내려받으면 남은 공간을 초과한다.
- **NightOwls**: 40시퀀스 279k 프레임 규모라 마찬가지로 여유 공간을 크게 잠식한다.
- 여기에 ② 저조도 개선 학습 시 생성될 **패치 크롭 캐시**와 YOLO 학습 산출물(`runs/`)이 추가로 공간을 요구하므로, 원본 데이터로 디스크를 채우면 학습 자체가 막힌다.

**대응 방침**

1. **보유 데이터로 선착수** — LoLI-Street 라벨(person 47,791박스) + ExDark + StairNet만으로 ③ 사전학습이 가능하다 (→ 6장). 두 데이터셋은 처음부터 *보강용*이므로 미설치가 일정을 막지 않는다.
2. **전량이 아닌 부분 취득** — 확보 시에도 전량이 아니라 필요한 하위 집합만 내려받는다.
   - NightOwls: `person` 계열 라벨이 있는 프레임 위주, training split 일부
   - AI Hub 인도보행: **Depth·노면 마스킹 제외**, 장애물 BBox 이미지 폴더 단위로 선택 다운로드
3. **저조도 합성 증강 파이프라인을 선행** — AI Hub는 대부분 주간이라 야간화 증강 없이는 받아와도 곧바로 쓰지 못한다. 증강 파이프라인을 먼저 만들어 두면, 취득 시 필요한 분량 판단이 정확해져 **불필요한 다운로드 자체를 줄일 수 있다.**
4. **외장 스토리지 확보 시 재개** — 용량 문제이므로 외장 SSD/HDD 추가로 즉시 해소된다. `data/`는 git 비추적이라 경로만 옮기면 된다.

> 정리하면 **"못 받는 것"이 아니라 "지금 받을 이유가 약해 미룬 것"**이다. 보강용 데이터를 위해 학습에 필요한 디스크를 미리 소진하는 것은 순서가 뒤바뀐 선택이다.
